# التقنيات والأدوات

المرجع المحدث الوحيد لإصدارات الأدوات والحزم هو
[`docs/00-overview/technologies.md`](../docs/00-overview/technologies.md).

بعد نقل المشروع إلى جهاز جديد شغّل:

```bash
npm run doctor:environment
```

يعرض الأمر احتياجات التطوير والويب والإنتاج وAndroid وiOS، ويقارن الحزم
المثبتة مع `package-lock.json` دون تثبيت أو تغيير أي شيء تلقائيًا. يمنع هذا
الملف المختصر تكرار قوائم الإصدارات في مكانين ثم تقادم إحداهما.
