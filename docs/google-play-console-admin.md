# Google Play Console Admin Page

## الهدف

صفحة `/super-admin/google-play-console` تعرض في بيئة التطوير فقط بيانات Google Play المتاحة عبر حساب الخدمة، بدون عرض أي مفاتيح أو كلمات مرور.

## ما تعرضه الصفحة

- حالة الربط الآمنة: اسم الحزمة، بريد حساب الخدمة، Project ID، ووجود ملف المفتاح.
- تفاصيل التطبيق من Google Play Developer API.
- مسارات النشر والإصدارات.
- قوائم المتجر واللغات.
- APK/AAB داخل جلسة قراءة مؤقتة.
- المراجعات، منتجات الشراء داخل التطبيق، والاشتراكات عندما تسمح الصلاحيات.
- البيانات الخام الكاملة لتسهيل الفحص.

## الحماية

- تعمل قراءة البيانات فقط عندما يكون التشغيل محليًا أو وضع التطبيق `development`.
- لا يتم إرسال `private_key` أو `private_key_id` أو كلمات مرور المتجر إلى المتصفح.
- خارج التطوير ترجع الواجهة الخلفية حالة مقفلة ولا تتصل بـ Google.
- كل نقطة قراءة مستقلة؛ إذا رفضت Google نقطة واحدة تظهر كتنبيه ولا تكسر الصفحة كلها.

## المتطلبات

- ملف حساب الخدمة: `assets/google-play/asole-73f1f-dc494a4b5159.json`.
- اسم الحزمة الافتراضي: `hgh.asol.app`.
- تفعيل Google Play Android Developer API في مشروع Google Cloud المرتبط بحساب الخدمة.
- منح حساب الخدمة صلاحيات مناسبة داخل Play Console.

## ملاحظة تحقق

إذا ظهرت رسالة أن `Google Play Android Developer API` غير مستخدمة أو معطلة، يجب تفعيل API في Google Cloud للمشروع المشار إليه في رسالة Google ثم إعادة تحديث الصفحة.
