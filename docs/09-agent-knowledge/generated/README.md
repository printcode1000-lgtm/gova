# Generated Agent Knowledge

Files in this directory are generated from the current repository by `scripts/docs/` and are **overwrite-only**.

Regenerate with:

```bash
npm run architecture:docs
```

Validate with:

```bash
npm run architecture:check
```

Generated artifacts cover repository structure, documents, routes, direct change impact, npm/runtime metadata, environment key names, a relational knowledge graph, and a search index. Environment values are never emitted.

Do not edit generated facts manually; change their source or generator and regenerate.
