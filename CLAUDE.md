# Working Rules

Binding for any agent (Claude Code or other) working on this project.

1. **No browser verification.** Don't use browser/preview tools to test or verify code. Focus on writing correct code only.
2. **Read docs before editing.** Before changing any part of the project, search `docs/` for files relevant to that area and read them to understand current behavior and constraints before making changes.
3. **Update docs on behavior change.** If a change alters previously documented behavior (not just a simple bug fix), update the relevant file(s) in `docs/` as part of the same change.
